# TransAutumnlin-Demo 57-web

奧鐵路線查詢工具的 GitHub Pages 純前端版本。

## Demo 57 主要更新

- 新增奧鐵固定路線色：
  - 林嶺本線、坦城支線：`#E3C800`
  - 騰北本線、山里支線：`#E51400`
  - 墘海線：`#4D9900`
  - 垣海線：`#1BA1E2`
  - 格肯海山手線：`#66CC00`
  - 屏城線快速、屏城線普通：`#FA6800`
  - 特急白鹿號：`#FFFFFF`
- 途經站改為左側連續彩色實線。
- 路線名稱直式顯示在線路左側。
- 起點、轉乘站、終點使用較大粗體字，不使用站名外框。
- 非轉乘普通站預設折疊為「途經 X 站」，可展開查看。
- 車站欄位維持可打字的下拉選單。
- 排列方式維持純下拉選單。

## GitHub Pages

使用 `main` 分支根目錄發布即可。
