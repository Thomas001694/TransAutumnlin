# TransAutumnlin-Demo 54-web（Demo 54）

純 HTML、CSS、JavaScript 的 GitHub Pages 網頁版。

## 車站欄位操作

- 點欄位右側箭頭：展開完整車站清單。
- 直接輸入文字：即時篩選符合的車站。
- 鍵盤操作：方向鍵選擇、Enter 確認、Escape 關閉。
- 經由站可直接留空，或選擇「不指定經由站」。

## GitHub Pages

將所有檔案上傳至儲存庫根目錄，Pages 設定為：

- Source：Deploy from a branch
- Branch：main
- Folder：/(root)

部署完成後，若仍顯示舊版，請按 `Ctrl + F5` 強制重新整理。
